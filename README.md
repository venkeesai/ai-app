# Multi-Modal AI Trading Terminal

Streamlit-based dark-mode FinTech dashboard with:
- Bidirectional LSTM price projection (TensorFlow/Keras)
- NLP sentiment fusion from Google News India RSS (NLTK VADER)
- Support/Resistance topology scanner
- Plotly candlestick chart, indicators, and ML buy/sell markers

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
